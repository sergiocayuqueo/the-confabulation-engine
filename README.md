## Overview

When an artificial intelligence system states something false, the common word for it is "hallucination." Borrowed from psychiatry, the term is fundamentally inaccurate: hallucination requires a perceiving mind, and large language models perceive nothing.

This repository hosts the full text and working references for **"The Confabulation Engine,"** a theoretical paper arguing that LLMs are better understood through a century-old neuropsychiatric lens: **confabulation**—the fluent, confident production of a false narrative by a system with no internal mechanism for knowing that it has strayed from the truth.

---

## Key Theoretical Contributions

* **Clinical Analogy**: Connects LLM error profiles to Gazzaniga & LeDoux’s split-brain "interpreter theory" and Bonhoeffer/Korsakoff clinical confabulation.
* **Refutation of Rival Frameworks**: Rebuts the "stochastic parrot" and "bullshit" (Hicks et al., 2024) models by showing that confabulation is not an occasional malfunction, but the continuous default process of narrative production itself.
* **Empirical Grounding**: Analyzes real-world legal filings (*Mata v. Avianca*) and empirical findings (Sui et al., 2024) showing false model outputs are measurably more narratively coherent than true ones.
* **Institutional Implication**: Argues that because LLMs cannot track truth internally, external verification systems must be engineered around them by deploying institutions.
